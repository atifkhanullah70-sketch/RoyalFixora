# Fixora

## Trusted Services. Right at Your Door.

Fixora is a modern frontend prototype for a local home-services platform.

Customers can discover different home services and submit service booking requests.

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Design
- WhatsApp Integration

No framework is required.

## How to Run

Simply open:

index.html

in Google Chrome, Microsoft Edge, Firefox, or another modern browser.

## WhatsApp

Fixora uses WhatsApp for booking communication.

Configured number:

+92 3481 969273

The number is stored in:

js/script.js

The variable is:

const WHATSAPP_NUMBER = "923481969273";

If the WhatsApp number changes in the future, update this variable.

## Important

This is currently a frontend prototype.

The project does not yet have:

- Database
- User authentication
- Admin dashboard
- Online payments
- Real professional verification
- Backend API
- Real-time booking management

These features can be added later using a backend such as Node.js, Python, PHP, or another suitable technology.
